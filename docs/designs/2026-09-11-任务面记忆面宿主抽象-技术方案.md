## 4. 风险覆盖（10 分）

| 风险类 | 有无涉及 | 分析与对策 |
|---|---|---|
| Compatibility 兼容 | 有 | SKILL 工具名泛化只改指代不改语义；dsh 路径仍映射到看板工具（适配层保持等价）；存量任务（看板内）不受影响 |
| Exception 异常 | 有 | 台账脚本：解析失败/字段缺失一律 exit 非 0 且**绝不静默绿**；非法状态跳步显式报错并给出允许的下一步 |
| Cache 缓存 | 不适用 | 无缓存面 |
| MQ 消息 | 不适用 | 无消息面 |
| State 状态机 | 有（核心） | 四态 + 转换白名单：`待执行→执行中`(claim)、`执行中→待确认`(report)、`待确认→已落定`(confirm)、`待确认→执行中`(reject)；越权/跳步一律拒 |
| Security 安全 | 有 | `confirm` 须带 `confirmedBy`+`confirmedVia`（omp=ask 交互引用），脚本拒绝无来源的 confirm；台账不存密钥/敏感值 |

## 5. 验证覆盖（10 分）

| 验证手段 | 内容 | 可执行入口 |
|---|---|---|
| Unit 单测 | `--selftest`：合法生命周期绿；非法跳步（未 claim 即 report / 未 report 即 confirm / 无 confirmedBy 的 confirm / 非法状态名）红，各自断言 | `node scripts/task-ledger.mjs --selftest` |
| Contract 契约 | 台账结构与字段集校验；CI 内 `--validate` 扫描全部台账文件 | `node scripts/task-ledger.mjs --validate` |
| Regression 回归 | 既有三项不回退：lint PASS、副本校验 PASS、dsh-architect 47 测试 PASS | 本地 + CI |
| Monitoring 监控 | CI 三 step（lint / 副本 / 台账）常态把关 | GitHub Actions |
| Rollback 回滚 | 分项 commit；契约条目可退（待审核前删）；脚本与 CI step 单点可撤 | git |
