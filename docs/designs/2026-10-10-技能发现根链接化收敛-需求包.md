# 结构化需求包：技能发现根链接化收敛

> 来源：主人 2026-10-10 会话——「`.claude/` 目录不是最适合的目录，深入系统性思考更合理的组织方式」+ 三项决策：**D-A** 认可链接化收敛目标架构（git 只留 `skills/`，宿主根全链接化）、**D-B** 授权 P0 可行性实证、**D-C** 实证通过后正式立项。
> 前置实证（本会话，全部可回源）：① dsh junction 热重载——`.dsh/skills/archify` 挂载后宿主即时发现（2026-10-10 实测）；② omp 容器 rw 直挂权威源——docker inspect + 容器内 13 技能全量可达（P0 实测）；③ T0 镜像补同步后 `check-skills-sync` 全绿（251 文件×2 镜像逐字节一致）；④ 独立评审两轮实证：镜像面漂移/机械门虚假绿/行尾漂移三类事故全部源于「多份物理副本」这一分发机制本身。

- **可验收目标**（可度量）：
  1. **单一事实源**：git 内技能面仅剩 `skills/`（`.claude/skills`、`.omp/skills` 两镜像目录退役出库，~250 文件）；
  2. **发现兼容不回退**：链接化后三类宿主**新会话**均能发现全部 13 技能——dsh（junction，已证）/ omp 仓库根会话（U1 首验）/ Claude Code（U1 并观察）；
  3. **bootstrap 脚本**：`scripts/link-skills.ps1` + `link-skills.sh`——一键（重）建全部发现根链接（幂等；默认 link 模式，per-host 可配 copy 兜底）；
  4. **链接健康检查**：`check-skills-sync.mjs` 改造为「链接健康检查」——逐根验证链接存在、可解析、目标=权威源（断链/缺链机械检出，替代内容比对）；
  5. **CI 适配**：ci.yml 技能同步步骤替换为链接健康检查（**提交需 `Gate-Approved` 标记**——ci.yml 在保护清单）；
  6. **KB/文档同步**：`reference/archify-integration.md` 纪律改写（5 处清单→链接模式）、`meta/glossary.md` 增「发现根/兼容链接」条目、AGENTS.md 技能挂载描述更新。
- **范围（做）**：上述文件 + docker/workspace 旧残留**处置登记**（清理移出本包——含 .git，内容归属待主人裁决，另列决策）。
- **不做项**（显式排除）：不改 `skills/` 权威源内任何技能内容；不动容器 rw 直挂形态（P0 实证的零同步保持）；不做 `.agents/skills` 实体目录方案（保持链接）；不处理 docker/workspace 残留目录的实体清理（另列决策）；不承诺对「不跟随链接的未知工具」的兼容（copy 模式为受限降级非保证）；不改 `packages/architect-core`（D11）。
- **假设**（标注依据）：① omp/Claude Code 技能扫描跟随目录链接——依据：文件系统透明性 + dsh junction 实证；omp 侧 U1 首验；② Windows junction 被目录扫描透明解析——依据：同上；③ 容器 rw 直挂形态不受本包影响——依据：P0 docker inspect 实测。
- **阻断项**：无——纯分发机制改造，MIT 无供应链引入；ci.yml 变更走 Gate-Approved 既有机制。
- **待确认**（已全部清除，2026-10-10 主人拍板）：
  - **Q1** 镜像退役节奏：**已决 = 单提交直接退役**（git rm 两镜像 + bootstrap 建链接同票完成；回滚=revert+copy 模式）；
  - **Q2** check-skills-sync.mjs 处置：**已决 = 改造为链接健康检查**（保留机械门）；

- **专项评审触发**：流程基建变更（技能分发机制重构）+ CI 修改（Gate-Approved）+ 自指改造（check-skills-sync 改自身）——评审仍由独立实例执行。
