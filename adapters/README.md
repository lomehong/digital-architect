# adapters · 宿主适配层

> SKILL 与知识库是**宿主中立**的（决策 D9，2026-09-10）：它们只规定流程语义与验收纪律；
> 各宿主的机制差异（会话内提问、审批、任务面、记忆面、技能挂载、检查工具安装）
> 一律收敛到本目录，一个宿主一个文件。
> 适配原则与套件联邦原则同构：**核心不动，适配显式，降级保守**。

## 适配文件必须覆盖的五个面

| 面 | 回答的问题 |
|---|---|
| 宿主判别 | 用什么特征识别当前会话跑在哪个宿主上 |
| 决策门 | 六类人工决策门（Unknown/Conflict/业务取舍/跨团队/合规/高风险）落在宿主的哪个机制 |
| 任务执行 | 方案落定后任务拆到哪；验收语义（自报 ≠ 完成）由什么承载 |
| 记忆沉淀 | 执行结果与经验沉淀到哪；Knowledge Evolution 回灌 `architect-knowledge/practice/` 的路径 |
| 挂载与工具 | 本方案（SKILL/知识库/检查器）在该宿主怎么安装、怎么被发现 |

## 宿主判别规则（SKILL 使用前执行）

1. 按各适配文件「判别特征」节对照**会话当前可用工具**：命中即采用该适配文件；
2. 多个宿主特征同时命中（如套件插件与 omp 工具并存）：按主人指定，未指定则默认 `dsh.md`；
3. 完全无法判别：**停止并问主人**——不得在错误的宿主假设下继续流程。
