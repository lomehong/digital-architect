## C2 大脑仓 git 镜像（本会话实施）

### 设计落点

| 项 | 实现 |
|---|---|
| 镜像持有 | `observatory/brain-mirror.mjs`（零依赖）：缺席自动 `git clone --origin brain`；remote 不一致报错不改写 |
| 只读同步 | `fetch --prune` + `merge --ff-only`；启动即同步 + 每 `--brain-sync-sec`（缺省 300s）周期同步（进程内建，无独立进程/计划任务） |
| 知识升级 | `POST /api/govern/knowledge` → 镜像内先同步 → 写文件 → `add` 指定文件 → `commit` → `push`（git 为权威，多副本经远端同步） |
| 冲突策略 | 分叉（ff-only 失败）/ push 被拒 → `reset --hard` 回滚到提交前基线（工作树一并还原）→ **拒写** + `platform.brain.sync` critical 留痕呈报，不静默强推 |
| 凭据 | `OBS_BRAIN_TOKEN` 环境变量 → 运行时在 `<镜像>/.git/` 生成 askpass 辅助（脚本无秘密，读进程环境）——令牌**只进平台进程环境**，不落盘明文、不进远端 URL、不进 `.git/config`；未设置则交给系统凭据助手；`GIT_TERMINAL_PROMPT=0` 非交互 fail-fast |
| 寻址 | 知识面（architect-knowledge 五类 + review-queue）：镜像模式读 `<镜像>/architect-knowledge`，随仓读 `<ROOT>/`（与 C1 配置寻址同思路）；启动参数 `--brain <url|路径>` / `--brain-dir` / `--brain-sync-sec` |
| 呈现 | `/api/snapshot` 与 `/api/health` 增 `brain` 状态（分支/head/落后/最近同步/冲突）；看板知识视图加知识面徽标（分叉 → 朱红「拒写待裁决」告警） |
