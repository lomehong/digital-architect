## 4. 风险覆盖

| 风险类 | 分析与对策 |
|---|---|
| Compatibility | 纯增量；不触碰既有三道门禁 |
| Exception | before 为空/全零（新分支/首推）→ 回退 HEAD~1..HEAD 并 WARN；diff 命令失败→FAIL（fail-closed） |
| Cache/MQ | 不适用 |
| State | 门禁无状态（每次现算） |
| Security | marker 可伪 = 残余风险 U1（可见性兜底）；fail-closed 设计使绕过必然红灯可见 |
