## 4. 风险覆盖

| 风险类 | 涉及 | 分析与对策 |
|---|---|---|
| Compatibility | 涉及 | 纯新增文件与 exports 键；既有消费方（preset 工具行、omp 配置）零感知；0.2.0 语义化版本 |
| Exception | 涉及 | 解析失败→R8 error（绝不静默跳过）；CLI 对缺失目录给出明确报错；lint 函数对空快照返回 error 而非抛异常（检查器不得成为阻断点，同 coverage 纪律） |
| Cache 缓存 | 不适用 | 显式声明（无缓存面） |
| MQ 消息 | 不适用 | 显式声明 |
| State 状态机 | 涉及 | lint 只读：不修改任何条目/台账；R4/R5 反映 status 流转现状而非约束流转 |
| Security 安全 | 涉及 | workflow 无写权限（contents: read 默认）；私有子模块拉取需凭据→U1：建议 fine-grained PAT（仅 lomehong/dsh-architect 的 Contents:read）配为 secret `SUBMODULE_TOKEN`，或 SSH deploy key；未配置前 CI 首跑会红并给出明确指引（可接受——红灯本身就是守门） |
