## 4. 风险覆盖（10 分）

| 风险类 | 有无涉及 | 分析与对策 |
|---|---|---|
| Compatibility 兼容 | 有 | 五问口径统一为严格后，既有四份方案若复评可能因「答 4 题」从过变不过——**不回改历史评分**；新评审一律新口径。renderReviewSkeleton 文案变更对已产出评审文档无追溯影响 |
| Exception 异常 | 有 | G3 校验脚本对「单侧新增文件」也必须报不一致（不能只 diff 共有文件）；脚本解析失败 exit 非 0，绝不静默绿 |
| Cache 缓存 | 不适用 | 纯文件/纯函数变更，无缓存面 |
| MQ 消息 | 不适用 | 无消息面 |
| State 状态机 | 有 | 方案状态流转不变（草稿→已评审→已落定）；知识条目如涉 G1 引用，走 待审核→主人确认 升级，不跳步 |
| Security 安全 | 有 | 子模块公开化暴露检查器源码——已核其内容为纯函数校验器，无密钥/内部端点（lint.ts/coverage.ts 实读确认）；CI 权限面维持 `contents: read` |
