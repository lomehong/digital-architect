## 设计落点

### 指令单生命周期（pull 模型，宿主侧不开端口）

```
主人（看板/API，管理员令牌门）
  → POST /api/govern/dispatch   平台发单：单号 GOV-<ts>-<rand> + HMAC-SHA256 签名（GOV_SIGN_KEY）
  → <数据根>/govern-orders/pending/<单号>.json
  ← GET /api/govern/orders      实例宿主 governor 领单（御符 token 认证，验「谁在领单」）
  → governor：验签 → 白名单校验 → 幂等去重 → 本地执行 → 回执
  ← POST /api/govern/receipt    平台归档 done/ + governance.receipt 事件（全量留痕）
```

### 防线对照（技术方案 §4 逐条）

| 方案防线 | 实现 |
|---|---|
| 御符 token 认证 | 领单/回执端点走 `verifyReporter`（yufu_verify，与上报通道同语义）；受保护模式下无 token 一律 401 |
| 指令单签名 | HMAC-SHA256，密钥 `GOV_SIGN_KEY` **只进平台/宿主进程环境**（不随单、不过 HTTP、不落盘）；验签不过=伪造，拒执行 + **critical** 留痕呈报 |
| 单号幂等 | 平台单号全局唯一 + 重发幂等（回执前重复领到同单）；governor 本地 `executed.ndjson` 去重——重复领到不重复执行，回执 dedupe |
| 命令白名单 | 双侧纵深：平台发单仅收 `task-ledger`(confirm/reject)/`doc-status`；governor 领单独立再校验（action、参数形状、脚本存在性、路径须在 `--allow-root` 内）——**签名合法但白名单外也拒** |
| 全量回执留痕 | 每单必有 `governance.dispatch` + `governance.receipt` 事件；执行/拒执/伪造全部落 `govern-orders/done/` 归档 |
| 生产台账纪律 | 地址簿登记实例发单须显式 `confirmReal=true`（2026-09-12 误操作防线的同款纪律，平台侧拦截） |
| 不用计划任务/隐藏窗口 | governor 为可见终端手动进程（pull 模型无监听端口）；fetch 带 15s 超时不会悬挂 |

### 关键实现

- `observatory/governor.mjs`（新，零依赖）：`--platform/--instance/--state/--allow-root/--once`；`YUFU_CREDENTIAL` + `GOV_SIGN_KEY` 环境变量注入；执行形状固定（arg 数组、不拼 shell）：`node <root>/scripts/task-ledger.mjs <sub> --id … --by … --confirmed-via observatory-governor --root …`；doc-status 仅改 frontmatter 首个 `status` 行且路径必须落在 `--allow-root` 内。
- `server.mjs`：`govDispatch/govClaim/govReceipt/govSnapshot`；无 `GOV_SIGN_KEY` **拒绝发单**（无签名不发单）；快照增 `governorOrders`；`http` 回调改 async（GET 领单端点需 await 御符验证——历史缺口：无体 GET 不能等 `req 'end'`）。
- 看板治理页：跨宿主发单按钮（复用任务号/台账根/操作者，台账根须填**实例宿主视角**路径）+ 文档 status 发单 + 指令单状态表（含签名密钥配置指示、伪造拒绝 critical 红标）。
- `pack.mjs` 收录 governor.mjs（独立部署包自带宿主侧 agent）。

## 实测证据（2026-09-12，`observatory/contracts/governor-e2e.mjs` 15 断言全过）

受保护模式平台（`--require-token` + 管理员令牌 + yufu 桩）+ 夹具远端项目（fake-ledger 隔离夹具 + 临时文档）：

1. 未认证领单 401；无管理员令牌发单 401；
2. 平台侧 action 白名单外拒单（400）；
3. 地址簿登记实例发单无 `confirmReal` → 400（防线沿用可证）；
4. **跨宿主 confirm 端到端**：发单 → governor 领单 → 本地执行 → 回执含 fake-ledger 执行形状（`--confirmed-via observatory-governor`）→ 快照「已完成」；
5. 跨宿主文档 status：`allow-root` 内 .md 的 `status: 草案 → 已落定` 本地改写成功；
6. **伪造指令单**（密钥不一致的 governor）：拒绝执行 + `refusal=signature` + critical 呈报事件；
7. 纵深负测：手工构造**合法签名**但 `action=shell` 的单 → governor 仍拒（whitelist）；
8. 幂等负测：已执行单号重复领到 → 不重复执行（dedupe 回执）；
9. 指令单全量事件过契约 v1（validate.mjs PASS）。

回归：render-smoke PASS（并实际拦截一处模板字面量 `\x` 非法转义——已修正）；brain-mirror-e2e 16 断言全过（C2 无回归）；pack 重建含 governor.mjs。
