# 可执行技术方案：技能发现根链接化收敛

## 0. 一句话与五问速答

git 内技能面收敛为**唯一权威源 `skills/`**（退役 `.claude/skills` 与 `.omp/skills` 两个物理镜像，~250 文件出库）；各宿主发现根改为**机器本地链接**（junction/symlink → 权威源），由一个幂等 bootstrap 脚本一键铺装与健康检查；`check-skills-sync.mjs` 改造为**链接健康检查**；容器保持 rw 直挂（P0 实证零同步）。治理不变量与 `skills/` 内容一处不动。

| 五问 | 速答 |
|---|---|
| 改哪里？ | 新增 `scripts/link-skills.ps1`+`link-skills.sh`（bootstrap+--check）；改造 `scripts/check-skills-sync.mjs`（内容比对→链接健康检查）；`git rm -r .claude/skills .omp/skills`（退役出库）；`.gitignore` 增两镜像路径；`ci.yml` 同步步骤替换（Gate-Approved）；KB/文档同步（archify-integration 纪律改写、glossary 增条目、AGENTS.md 挂载描述） |
| 为什么改？ | 实证三事故同根因：**多份物理副本靠人肉保持一致**——G2 docker 双根漂移（独立评审发现）、rebase 行尾漂移（4 文件）、机械门对容器双根虚假绿（复评 R1）。链接化后副本不存在，漂移类问题整类消失 |
| 影响谁？ | 全部宿主的技能发现——**新克隆/新机器需先跑一次 bootstrap**（一条命令，README/AGENTS.md 显式提示）；运行中会话不受扰；容器 rw 直挂不变 |
| 如何验证？ | 机械门=bootstrap --check 全绿（13 技能 × 3 根链接齐且可解析）+ knowledge-lint PASS；行为门=三宿主新会话技能发现实测（dsh 已证 / omp 本地 U1 / 容器直挂已证） |
| 还有什么没确认？ | U1 omp/Claude Code 对链接的跟随首验（P1 实测）；U5 docker/workspace 旧挂载残留处置（另列决策，登记） |

## 2. 系统覆盖（逐文件修订设计）

### 2.1 新增 `scripts/link-skills.ps1` + `scripts/link-skills.sh`（bootstrap）

- **技能清单**：动态枚举 `skills/*/SKILL.md`（不硬编码名单——新技能零维护自动覆盖）；
- **根清单**：`.claude/skills`、`.omp/skills`、`.dsh/skills` 三根（.agents/skills 本期不做，需求包不做项延伸）；
- **link 模式**（默认）：Windows=`New-Item -ItemType Junction`（ps1）/ `cmd mklink /J`；POSIX=`ln -sfn`；幂等——已存在且指向正确则跳过，断链/缺失则（重）建；
- **copy 模式**（`--mode copy`，per-host 兜底）：物理复制（给不跟随链接的宿主降级用）；
- **`--check` 模式**：只验证不修复——逐根逐技能断言「链接存在且解析到权威源对应目录」，缺失/断链/指错 → 列出并以非零退出（fail-closed）；
- **退出码**沿用 check-skills-sync 语义：0=pass、1=fail、2=内部错误。

### 2.2 改造 `scripts/check-skills-sync.mjs` → 链接健康检查

- `MIRRORS`（内容比对）替换为 `ROOTS`（链接健康断言）：每根每技能「链接存在 + 解析目标 = `skills/<name>` + `SKILL.md` 可读」；
- 保留：退出码语义、脚本自指保护（本脚本仍在改造自身，变更提交需 `Gate-Approved`——脚本不在 gate-guard PROTECTED 清单，但按其精神与本次需求包裁定执行标记）、--help；
- 删除：双镜像内容比对逻辑（随镜像退役失去对象）。

### 2.3 镜像退役 + CI 替换（T4，`Gate-Approved` 必需）

- `git rm -r .claude/skills .omp/skills`（~250 文件出库）；
- `.gitignore` 增 `.claude/skills/` 与 `.omp/skills/`（链接为机器本地产物）；
- `ci.yml`：原 check-skills-sync 步骤替换为 `bash scripts/link-skills.sh --check`（ubuntu runner 上建 POSIX symlink 后自检；runner 无需真实宿主）——**该提交触及 ci.yml，须携带主人 `Gate-Approved` 标记**；
- README/AGENTS.md：新增「新克隆先跑 `scripts/link-skills` bootstrap」显式提示。

### 2.4 KB/文档同步

- `reference/archify-integration.md` 纪律节改写：5 处同步清单 → 「更新权威源即全宿主生效；发现根链接由 bootstrap 维护」；
- `meta/glossary.md` 增两条：「发现根」（宿主扫描技能的目录）、「兼容链接」（指回权威源的机器本地链接）；
- `AGENTS.md` 挂载描述行更新（bootstrap 提示）。

## 4. 风险覆盖

| 风险类 | 对策 |
|---|---|
| Compatibility | 某宿主不跟链接 → 该根 `--mode copy` 降级（受限但可用，U1 首验后定 per-host 策略）；POSIX/Windows 双脚本 |
| Exception | 断链/缺链 → bootstrap 幂等修复；--check fail-closed（退出码非 0 阻断 CI） |
| State | 新克隆/新机器 = bootstrap 一次；README+AGENTS.md 双处显式提示；**快速启动/重启不影响链接（文件系统对象持久）** |
| Security | 链接目标固定为权威源（不指向任何外部路径）；ci.yml 变更走 `Gate-Approved` 主人标记；无密钥面 |
| 数据 | 零出域；退役文件在 git 历史可回溯 |
