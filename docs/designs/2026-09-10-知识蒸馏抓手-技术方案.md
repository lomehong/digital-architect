## 附录 A：knowledge-distill SKILL 规格

- **frontmatter**：`name: knowledge-distill`；`description:` 覆盖触发词（蒸馏/入库/知识采集/公众号文章/复盘蒸馏）与一句话职责；
- **流程八步**：①探测桥（bridge-config；不在位→停止不绕行）②打开/载入源（文章 URL、方案、串讲、复盘文档）③抽取文本（浏览器快照或 read）④图示解读（read_image，图存 `evidence/images/` + manifest，条目内注「图 N 多模态解读」）⑤领域判定（新领域→建五类目录；既有领域→按主题定位落点）⑥落库（frontmatter 六字段齐，`status: 待审核`，来源含 origin+ref）⑦台账登记（source-manifest 增/更新来源；review-queue 增待审核条目；对应 index.md 增行）⑧git 中文提交；主人确认后升级 status 并更新台账；
- **降级纪律**：桥缺席→停止问主人；来源不可回源→不落库（登记 Unknown，不编造）。

## 附录 B：台账 schema

```yaml
# source-manifest.yaml —— 蒸馏来源清单（引用不复制；一条来源可被多条目引用）
- id: src-<slug>              # 稳定 ID
  origin: 来源名               # 与条目 frontmatter source.origin 一致
  ref: URL 或路径
  type: 公众号文章 | 内部文档 | 宪章 | 口头指示 | 源码
  date: 首次使用日期
  used_by: [相对条目路径, ...]
```

```yaml
# review-queue.yaml —— 待审核队列（与 frontmatter status: 待审核 一一对应；确认后移除并更新 frontmatter）
- file: 相对条目路径
  reason: 待审核原因
  queued: 登记日期
```

```markdown
<!-- 各目录 index.md —— 一行一条：| 条目 | 一句话定位 | 状态 |（状态与 frontmatter 一致） -->
```
