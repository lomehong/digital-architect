- **可验收目标**（可度量）：
  1. **流程 D 六件技能**落地 `skills/`（中文改编版，每件 SKILL.md 含 frontmatter name+description，走链接化分发）：
     ① `grilling` 拷问原语——对需求/方案/决策无情问询至设计树闭合（流程 K digest 第二步的通用化，可独立调用）；
     ② `spec-align` 规格对齐——对话收敛成规格 + quiz 触碰模块 + GLOSSARY/ADR 内联维护（grill-with-docs 改编）；
     ③ `ticket-split` 拆票——曳光弹切片 + 阻断边显式 + expand–contract 例外 + quiz 迭代（to-tickets 改编，阻断边映射看板 `blocked_by`）；
     ④ `impl-discipline` 实现纪律——tdd 红绿循环 + diagnosing-bugs 诊断闭环 + 小步提交（流程 D 执行段在目标项目侧的纪律）；
     ⑤ `dual-axis-review` 双轴评审——标准轴+规格轴并行子代理（今日已验模式沉淀为技能）；
     ⑥ `retro` 回顾——会话后环境改进建议，按严重度排序；
  2. **治理不变量内嵌**：六件技能正文均显式引用本仓不变量（自报≠完成 / confirm 归主人 / 治理动作不静默 / 证据回源）；

  4. **setup 本仓化**：tracker=看板/台账、labels、docs 落点写成流程 D 技能常量节——**不依赖上游 setup-matt-pocock-skills**；

  6. **全绿门**：knowledge-lint PASS + 链接健康检查全绿（13+6=19 技能 × 3 根）+ dsh 宿主新会话发现新技能实测。
